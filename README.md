## 1. Project Description

### 1.1. Purpose

AI Store Assistant is an intelligent conversational agent designed to automate customer support operations in retail environments.

The system uses Large Language Models (LLMs), structured datasets, and document retrieval techniques to provide customers with contextualized information regarding products, orders, promotions, and store policies.

The application integrates the Google Gemini API with locally managed data sources, enabling the retrieval and processing of relevant information before generating customer-facing responses.
